# CivisCams | Advanced Tactical Surveillance
**Automated Enhanced Locator & Identification System (AELIS Core)**

CivisCams is a high-performance computer vision suite designed for real-time human tracking, perimeter monitoring, and forensic detail recovery.

## 🚀 Features
*   **Multi-Target Persistence:** Assigns unique IDs to subjects for continuous tracking.
*   **Smooth-Motion Engine:** Uses Linear Interpolation (Lerp) to stabilize tracking boxes.
*   **Restricted Perimeter:** Real-time "Breach" detection using virtual tripwires.
*   **Forensic Detail Recovery:** Sharpened digital zoom for high-priority target identification.

## 🛠️ Installation
1. Clone the repo:
   `git clone https://github.com/enderairofficial/CivisCams.git`
2. Install dependencies:
   `pip install -r requirements.txt`
3. Run the system:
   `python main.py`

## ⌨️ Controls
*   **Q:** Terminate system feed.
